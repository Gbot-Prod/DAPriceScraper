Built to be easy to depend on

The DA publishes prices as PDFs. This API does the tedious part: finding each new report, parsing every table, checking the numbers, and keeping a clean history.

No sign-up

No API keys, no accounts. Plain GET requests with CORS open to any origin, so it works straight from the browser.

JSON or CSV

Every price endpoint speaks both. Add ?format=csv and open it in Excel or Google Sheets.

History and price bands

Time series per commodity, plus min, max, median and latest price over any window of up to a year.

Validated and traceable

Large day-over-day jumps are flagged, and every price links back to the exact DA report and file checksum it came from.

Quick start

Get today's prevailing prices in one request.

curl "https://your-host/prices/latest?available_only=true"

# Same data as a spreadsheet
curl "https://your-host/prices/latest?format=csv" -o prices.csv
const res = await fetch("https://your-host/prices/latest?available_only=true");
const { as_of_date, items } = await res.json();

for (const item of items) {
  console.log(item.commodity_name, item.specification, item.price_prevailing, item.unit);
}
import requests

res = requests.get("https://your-host/prices/latest", params={"available_only": True})
res.raise_for_status()
data = res.json()

for item in data["items"]:
    print(item["commodity_name"], item["price_prevailing"], item["unit"])

Frequently asked questions

Is this official Department of Agriculture data?

The prices come from the DA's own Daily Price Index reports, but this is an independent, community project. It isn't affiliated with or endorsed by the DA. For anything official, check the original reports on the DA website. Every price in the API links back to the report it came from through /reports/{date}.

How often is the data updated?

The DA publishes one Daily Price Index per day. A scheduled sync job (twice a day by default) picks up each new report shortly after it's published. The /health endpoint tells you the latest report date.

Which areas are covered?

The National Capital Region (Metro Manila). Each report surveys around 30 public markets; /reports/{date} lists exactly which ones. Endpoints take a region parameter so other regions can be added later.

What does "prevailing price" mean?

It's the price most commonly observed across the surveyed markets for that commodity on that day, as reported by the DA. If a commodity wasn't available in the markets that day, the API returns "is_available": false and "price_prevailing": null.

Are there rate limits?

Yes, to keep it free for everyone: 60 requests per minute, 1,000 per hour and 5,000 per day per IP address. That's plenty, since prices change once a day. Responses support ETag caching, so repeat requests for unchanged data are cheap. If you need more, self-host it.

Can I host my own copy?

Yes. It's MIT licensed and ships as a single Docker image that runs both the API and the daily sync job, with SQLite or PostgreSQL. See self-hosting in the docs.
